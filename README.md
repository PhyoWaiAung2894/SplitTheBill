# Split The Bill

# Features

###• Bill Splitting: Calculate the amount each person should pay, including tip.
###• Tip Percentage Picker: Select a tip percentage from 0% to 100%.
###• Dynamic Currency Formatting: The app automatically formats the currency based on the user’s locale.
###• Keyboard Management: The app features a “Done” button to dismiss the keyboard easily.
